# הלימוד היומי שלי

אפליקציית ווב (PWA) למעקב אחרי לימוד יומי: ספרים, סימון יומי, השלמת ימים שעברו, סטטיסטיקה וגיבוי.
כניסה עם חשבון Google והנתונים נשמרים ב-Firebase.

## מבנה הקבצים
- `index.html`: הדף הראשי
- `css/style.css`: עיצוב
- `js/app.js`: המסכים וההתנהגות
- `js/schedule.js`: חישוב המנה היומית, ההתקדמות והסטטיסטיקה
- `js/books.js`: רשימת הספרים המוכנים
- `js/hebrew.js`: מספרים עבריים, תאריך עברי, חגים
- `js/store.js`: שמירה בענן (Firebase) או מקומית (מצב הדגמה)
- `js/config.js`: **כאן מדביקים את הגדרות Firebase**
- `firestore.rules`: חוקי האבטחה שמעתיקים למסוף Firebase

## הפעלה מקומית
```
python3 -m http.server 8000
```
ואז לפתוח את http://localhost:8000
